# TaskMaster Web App

A beginner-friendly single-page ToDo application built with HTML, CSS, and JavaScript. TaskMaster demonstrates CRUD operations, DOM manipulation, responsive design, and persistent browser storage using `localStorage`.

## Tech stack

- HTML
- CSS (Flexbox / Grid)
- JavaScript (ES6)
- `localStorage`

## How to run

1. Open `index.html` directly in your browser.
2. If your browser blocks local files, serve the folder with a simple local server:

```powershell
python -m http.server 8000
```

Then open `http://localhost:8000`.

## Features

- Add new tasks with validation
- Edit existing tasks inline
- Delete tasks
- Mark tasks complete or active
- Filter tasks by All / Active / Completed
- Persist tasks automatically in browser storage
- Responsive layout for desktop and mobile
- Keyboard accessible form and edit controls
